Projects

Full Adder

A Full Adder is a fundamental building block in digital electronics used to perform the arithmetic addition of three binary digits. Unlike the Half Adder, which can only add two binary digits and generate a sum and a carry, the Full Adder adds three inputs — including a carry-in from a previous addition stage — and produces a sum and a carry-out. Full Adders are essential components in the design of arithmetic logic units (ALUs), digital computers, and embedded systems where binary addition is performed.

7 Segment Display

A 7-segment display is an electronic display device used to show decimal numbers using seven individual LED segments. It is commonly used in digital clocks, calculators, and measuring instruments.
A 7-segment display is an electronic visual display device that is used to display decimal numerals (0–9) and some alphabetic characters using a set of seven LED segments. Each segment can be individually controlled (turned on or off) to form numbers and certain letters.

Bluetooth controller opener using servo motor

The Bluetooth controller opener using a servo motor is a simple project that allows wireless control of a lock or door. A Bluetooth module receives commands from a smartphone, and these are processed by a microcontroller like Arduino. Based on the signal, the servo motor rotates to open or close the mechanism. This makes it an easy, low-cost, and convenient way to control access.
